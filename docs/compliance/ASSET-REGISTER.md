## 4. Fonts, icons, third-party marks

* **Fonts loaded** (`app/layout.tsx`, `app/_marketing/fonts.ts`): Inter via `next/font/google` (downloaded at build, **served from CrewFlow's own origin**; CSP `font-src 'self' data:` and no `fonts.googleapis.com` / `fonts.gstatic.com` string anywhere in `app lib components next.config.ts middleware.ts vercel.json`: **VERIFIED**), SIL OFL 1.1; Clash Display + Satoshi via `next/font/local` (ITF Free Font License). PDFs use built-in Helvetica. No remote font host, no icon font.
* **Icon library**: `lucide-react` 0.460.0, ISC (portions MIT, Feather): **VERIFIED** (LICENSE read). No Font Awesome / Material / Heroicons packages. A handful of inline SVG glyphs (`app/payment/*`, `app/admin/pulse`, charts, `_book-demo-modal.tsx`, `login`) are simple geometric paths (checks, X, sparklines) authored in-repo.
* **Third-party marks**: the only third-party brand artwork in the product is the **Google "G"** and **Microsoft four-square** inline SVGs on the sign-in buttons (`app/(auth)/login/page.tsx`, `GoogleIcon`/`MicrosoftIcon`). Both providers permit their official marks on "sign in with" buttons if used unaltered and per their button guidelines; the guidelines (spacing, label text, light/dark variants) were not checked against the markup here: **NEEDS-FOUNDER/design review (Q7)**. No customer, partner, payment-scheme (Visa/Mastercard), Stripe, Xero, Sage or QuickBooks logo is shipped; Xero appears as plain text only (`components/marketing/home/{faq,switch-trust,job-journey,pricing-block}.tsx`, `app/(site)/pricing/page.tsx`), and `app/(marketing)/compare/page.tsx` names Procore, Jobber, Simpro, Tradify and Buildertrend as text (nominative use in comparative advertising is a counsel question, not an asset issue). `docs/redesign/CREATIVE-DIRECTION.md` records the deliberate decision: "no customer logos, no metrics, no testimonials".
* **Email**: no email image assets; transactional mail has no `<img>` in `lib/email`, and the `emails/` template directory referenced by the `email` script does not exist.
* **Audio / video / animation / Lottie**: none in the repo (see section 1).
